# MOBIS ENERGY — Website vitrine

Site vitrine en français uniquement réalisé avec Next.js 14 et React.

## Démarrage local
1. Installer Node.js (version LTS recommandée).
2. Extraire le projet.
3. Ouvrir un terminal dans le dossier `mobis-energy-website`.
4. Exécuter :

```bash
npm install
npm run dev
```

5. Ouvrir http://localhost:3000

## Personnalisation avant mise en ligne
- Vérifier les coordonnées, l'adresse et les références clients.
- Remplacer les illustrations CSS par des photos réelles autorisées de MOBIS ENERGY.
- Ajouter les logos des références clients avec leur accord.
- Configurer le domaine `mobis-energy.ma` chez le registrar et le relier à l'hébergement choisi.
- Prévoir une adresse email professionnelle et un formulaire de contact avec traitement côté serveur.

Le contenu initial reprend les informations présentes dans la brochure fournie. Les éléments graphiques industriels sont des illustrations CSS temporaires.
